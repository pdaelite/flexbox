一、为什么需要Flexbox？

在Flexbox之前，我们使用：

  • float: 需要清除浮动，布局复杂，不易理解。
  • inline-block: 会产生额外的空间间隙。
  • position: absolute: 脱离文档流，需要计算位置。

示例：响应式表单布局

600px

Flexbox（弹性盒子布局）是一种一维的布局模型，能更高效地处理元素排列、对齐和空间分配。

Flexbox的优势：

  • 方向无关：不依赖于块状或行内布局，可以轻松处理不同方向的布局。
  • 空间自动分配：容器可以自动计算和分配子项目的空间，响应式适配能力极强。

二、Flexbox的核心概念

1. 两个核心角色：

  • 弹性容器：设置了display: flex的元素。
  • 弹性项目：弹性容器的所有直接子元素。

2. 两条核心轴：

  • 主轴（Main Axis）：默认是水平方向，由flex-direction属性决定。
  • 交叉轴（Cross Axis）：与主轴垂直，默认是垂直方向。

3.3 justify-content - 项目在主轴上的对齐方式

3.7 gap - 项目间距

定义项目之间的间距：gap 属性是在 Flexbox 项目之间添加间距的方法。它比使用 margin 更简洁，因为它只会在项目之间添加间距，而不会在容器边缘添加间距。

gap 属性可以接受一个或两个值，分别对应主轴和交叉轴的间距。

  • 如果只提供一个值，那么该值将同时应用于主轴和交叉轴。
  • 当设置两个值时：第一个值表示行与行之间的间距（row-gap）；第二个值表示列与列之间的间距（column-gap）。

实践练习 9：flex-basis 与 flex-grow flex-shrink协同

使用 flex-basis 与 flex-grow flex-shrink 协同设置固定侧边栏布局：

flex属性是flex-grow、flex-shrink和flex-basis的简写：

语法格式：flex: flex-grow flex-shrink flex-basis;

缩写值 等价写法 效果说明
默认值 flex: 0 1 auto; 不放大、可收缩、基准尺寸为自身宽 / 高（内容优先）
flex: 1; flex: 1 1 0%; 可放大、可收缩、基准尺寸 0（等分容器空间的核心）
flex:auto flex: 1 1 auto; 可放大、可收缩、基准尺寸为自身宽 / 高（先内容后占剩余空间）
flex:none flex: 0 0 auto; 不放大、不收缩、基准尺寸为自身宽 / 高（固定尺寸，不受容器空间影响）
